# Firmware and interface audit, November 2026

Owner request (2026-11-02): run a tight ship, with no wasted RAM and clean structure, and
check every screen against Apple's Human Interface Guidelines (the `apple-hig` skill in
claude-tools, review checklist and constrained-device transfer guide). Measured on the
owner's X3 and in the simulator; commit `d04dfff`.

## Firmware: done in this audit

1. **Reader text window moved from the stack to the idle heap.** The reader held a 48 KB
   window on the stack and had **9.8 KB** stack left with a card article. The heap only
   serves the radio during a Receive, so it is free while reading. The window now comes
   from the heap (falls back to 32 then 16 KB, never panics). Measured with the built-in
   sample: stack left **20.2 → 70.2 KB**; with a card article **9.8 → 59.5 KB** (owner test).
2. **TLS spike removed** (`tlsprobe.rs`, serial `tls`). ADR 026 is settled; Receive has its
   own TLS path.
3. **Display test knobs removed** (`display mode`, `epd cdi`, `epd pofs`). The owner's tests
   chose mode 0, CDI 0x29 and power-off sequence 0x20; history keeps the rest.
4. **Firmware clippy is clean** for the first time (`drop(list)`; `Link` size gap allowed
   with its reason: one per session).
5. **Shared key wait** used by About and the CrossPoint confirm.
6. Flash `.text` **942.2 → 917.6 KB** (−24.5 KB).
